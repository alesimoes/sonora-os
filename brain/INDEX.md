## Decisions
- [ADR-0001](decisions/ADR-0001-engine-from-scratch.md) — engine written from scratch, not a fork of Ardour.
- [ADR-0002](decisions/ADR-0002-debian-base.md) — Debian stable as the distribution base.
- [ADR-0003](decisions/ADR-0003-pipewire-jack-api.md) — PipeWire as the server, JACK API as our client interface.
- [ADR-0004](decisions/ADR-0004-no-proprietary-reverse-engineering.md) — workflow cloning is in scope, binary reverse engineering is not.
- [ADR-0005](decisions/ADR-0005-usb-boot-persistence.md) — hybrid ISO plus a persistence partition for projects.
- [ADR-0006](decisions/ADR-0006-qt6-ui-toolkit.md) — Qt 6 for the shell, custom GPU scene-graph items for meters and timeline; the UI pulls at 60 Hz, the audio thread never pushes.
- [ADR-0007](decisions/ADR-0007-modules-contracts-and-squads.md) — modules by owner (`contracts/`, `common/`, `engine/`, `drivers/`, `ui/`, `plugins/`, `interchange/`), a dependency DAG enforced in CI, the RT boundary by module, contract change rules, squad mechanics and a six-step migration; engine and UI as separate processes, and Phase 3/4 work opened early under a fixed scope (both owner decisions, 2026-10-12). Updated with lessons from M1: three illegal edges until M4, so M4 merges before M5; tests live with their subject module; ctest labels go in M5; M2 is a `contract/backend` PR with `noexcept SONORA_RT`. Owner amendment 2026-10-13: §10's early Phase 3/4 scope limit lifted for the Complete DAW milestone. Updated again with the backend contract as landed: `make_backend` in `engine/app`, a `drivers/support` module, ports per device, DeviceGone and Stalled, `fatal_reason` by value, mlockall; the device policy as revised by the owner (2026-10-13): the USB interface, else after the wait the one onboard device, with a setting file.
- [ADR-0008](decisions/ADR-0008-portability.md) — portability (owner, 2026-10-12): neutral modules are standard C++17 only, platform code sits in `drivers/*`, `engine/app`, `ui/tui` and `common/platform`; `SONORA_PLATFORM` selects linux/neutral/windows(reserved); a required MSVC `windows-latest` job builds and tests the neutral modules; Windows backend will be ASIO, its licence unverified; Linux first.
- [ADR-0009](decisions/ADR-0009-timeline-snapshots-and-plan-swap.md) — accepted (engine owner, 2026-10-13): the edit state is an immutable value and undo a pointer, bounded by bytes with an engine-sent undo floor; resolved operations through a pure `apply` are both undo and UI replication; sources append-only and mix outside undo; playlists never overlap; a plan is published only once its audio is resident in per-plan chunk slots, retired by a seq_cst block counter; takes close in-band while rolling; canonical strict JSON through a new `common/json`. Update 2026-10-13: hardware measurements (Unverified 1, 2, 5, 7, 8) move to OS 1; laptop proxies before M8 merges. Update 2026-10-13 (playback on M4/M7): one document, the server's; its control thread is the document thread and owns `PlaybackController`; closed takes enter it as `AddSource` + `RecordTake`; `transport.play` through existing catalog ids, the record reply held until the residency gate resolves; `TakeDocument` and #31's interactive-loop changes dropped.

- [ADR-0010](decisions/ADR-0010-kiosk-compositor.md) — **Accepted by the owner 2026-10-13.** labwc as a configured kiosk (no keybinds, UI always-on-bottom, editors floating via lazy Xwayland), Qt on native Wayland, logind via `libpam-systemd`; engine, compositor, UI and tty2 TUI in independent units with an `OnFailure` fallback to tty2. sway is the fallback if labwc fails on real hardware; cage, weston kiosk-shell and EGLFS (not in Debian's Qt) rejected.

- [ADR-0011](decisions/ADR-0011-native-plugin-suite.md) — **Proposed.** The native plugin suite: standard LV2/VST3 plugins from one codebase (DPF behind our own `Processor` interface), hosted like any third-party plugin; only meters run in the engine, and moving a processor (the master chain first) into the engine is a gated amendment; neutral `common/dsp` + `plugins/native/<name>`, editors drawn by `sonora-ui`, a `dsp-engineer` role; measured quality bars, golden files and per-instance CPU classes at q128; physical models validated against SPICE, never against a commercial plugin; AI chooses parameters and DSP makes the sound, so ONNX Runtime runs only in `sonora-analyze`, while the amp captures run on our own RT-safe NAM-class kernels in the host; the mix assistant emits undoable model-operation plans, reverb/delay first; an optional Claude layer over features, never audio (owner to rule on network, cost and privacy); our own names, no trademarks or artist names; work order N0–N7.
- [ADR-0012](decisions/ADR-0012-plugin-hosting-m9.md) — **Accepted in part** (M9). One plugin host per insert chain, depth 1, the audio thread never waits; one broadcast `FUTEX_WAKE` per callback on a read-only clock region (auditor: accepted provisional, **gate off, timer-paced hosts by default** until a bare-metal 18/64-host measurement under `stress-ng --futex` shows max < ~130 µs; slots retired by epoch with generations, engine-only `values_seq`, capped first-submit copy, 64-frame fade-out on a miss); a missed block is silence ramped back in, 8 in a row remove the chain, any miss fails a bounce; the five `protocol.h` TODO(accept) items resolved (block-tagged params + last-value table, format-native values, never-reused regions with make-before-break restart, swap rules, layout 1 with size asserts and exit code 3); inserts in `common/model` and session format v2 (pre-fader, A–J, state files in `Plugin State/`); `TrackSource`/`InsertChain`/`TrackFader` plan nodes with builder-set `delay_frames`; additive control API (protocol 3, state block 2). Owner: O1 insert undo (default undoable), O2 editor keyboard focus. Ordered implementation checklist.
- [ADR-0014](decisions/ADR-0014-midi-model-and-realtime-path.md) — **Proposed.** MIDI (DAW 6): track kinds audio/MIDI/instrument; MIDI regions in `common/model` as windows onto shared, copy-on-write sequences stored inline, non-overlapping, in ticks at 960,000 per quarter; the frame-anchored tempo map kept, with one exact 128-bit integer frames↔ticks↔bars conversion (`MusicalMap`, `ui/qt` moves onto it) under bounds (bpm 1–1000, power-of-two meters, ≤ 384 kHz); session format v4, ports by name; MIDI ports in `contracts/backend` as fixed per-block `MidiBuffer` slots at frame offsets (this ADR is the ADR-0007 §6 amendment); plan carries MIDI as frames; endings never dropped (2,064 reserved of 4,096), trackers after the delay queue, chase slots retired by epoch; instruments as chains with an event area and a carry buffer for skipped submits, transport in the clock region (`contracts/plugin` layout 2, amends ADR-0012 §2/§7.1); takes stamped against the audio clock and written live as SMFs whose tick is a frame, sync-then-patch checkpoints; SMF interchange in `sonora-convert`; version numbers are the next free at landing; phases M-0 to M-7. Revised with the rt- and plugin-engineer reviews (#93). Owner: O1–O8.

## Research
- [Multichannel USB interfaces](research/multichannel-usb-interfaces.md) — Pro Audio profile, WirePlumber state hooks, port ordering; what is verified and what is not.
- [ADR-0007 measurements](research/adr-0007-measurements.md): the six "Unverified" items. RTSan is available (`clang-22` in trixie main; the default clang 19 lacks it). 8-byte atomics are lock-free on amd64 and arm64. Container IPC figures: socket and seqlock costs are fine, but a seqlock publisher must be paced and spinning at FIFO hits RT throttling. `snd-dummy model=rme9652` gives 26 ordered AUX ports in QEMU. cage maximizes parentless X11 editors.
- [Pro Tools and Logic key bindings](research/protools-logic-key-bindings.md) — every binding in both profiles checked against Avid's and Apple's own guides; corrections, collisions, the Commands Keyboard Focus problem, and what the schema cannot express.
- [Qt shell render cost](research/qt-shell-render-cost.md) — 18 meters at 60 Hz on llvmpipe only: about one core, 0.04 ms GUI tick; no GPU figure yet; the software scene graph cannot draw the meters at all.
- [USB stick layout](research/usb-stick-layout.md) — the ISO's MBR already has the ESP as partition 2, so persistence is 3; parted cannot edit it; the overlay lives in `home/rw`; `systemd.run=` needs `systemd.unit=` on this image.
- [BWF interop](research/bwf-interop.md) — takes checked with ffprobe, soxi, libsndfile, mediainfo and headless Ardour 8.12 (`tools/test-bwf-interop.sh`, CI job `interop`). All 36 files open as 24-bit 48 kHz at the right length, and Ardour places each at its TimeReference, including a non-zero take 2. Defect: OriginationDate/Time empty. Ardour treats TimeReference 0 as no timestamp. The writer wraps sizes past 4 GB instead of stopping.
- [Native plugin suite](research/native-plugin-suite.md) — literature, not measurement: published technique, parameters, oversampling, estimated cost class and validation for each first-party plugin (EQ to mastering, opto/FET levellers from public schematics, tube/transformer/tape, amps and cabs); BS.1770-5 true-peak is 4x at 48 kHz; AI parts (mastering analysis, timbre match, tuner, mix assistant, reverb/delay suggestions) are analysis-time except neural amp models and DSP pitch tracking; licence tables for code and datasets (RAVE, DeepAFx-ST, Diff-MST, madmom/Essentia models, MedleyDB, MUSDB18, Open-Unmix weights are non-commercial: excluded; CREPE weights trained on MedleyDB-derived data); legal notes.
- [Open data and DSP sources](research/open-data-and-dsp-sources.md). A licence survey, read from the sources on 2026-10-13. Nothing was downloaded or run.
  - **Shippable (CC BY 4.0):** VocalSet, vocadito, GuitarSet, Dagstuhl ChoirSet, EGFxSet, SignalTrain, VCTK, Arni and Motus RIRs.
  - **Non-commercial:** MUSDB18-HQ, MoisesDB, MedleyDB, MTG-Jamendo, IDMT-SMT-Guitar, MDB-stem-synth, EARS and GTSinger.
  - **Excluded as unclear:** NUS-48E, MIR-1K, EGDB and the MIT IR Survey.
  - **Captures and IRs:** TONE3000 captures are not redistributable (T3K licence). No cabinet IR set has a licence we could verify.
  - **Weights:** Spleeter's are MIT by Deezer's own statement, and it is the least-bad separation model. Demucs, Open-Unmix, CREPE, SwiftF0, PESTO and Basic Pitch weights rest on non-commercial or unclear data.
  - **Open question:** Slakh and StemGMD are MIDI rendered through commercial instruments; it is open whether ADR-0011 §4.6 excludes them.
  - **Code:** a licence table for about 40 DSP projects and about 35 neural-DSP repositories.
  - **Amps, speakers, mics:** a "virtual capture" pipeline (SPICE of published circuits plus maker T/S curves) with its limits and validation plan; mic modelling; vocal-balancing data. Biggest gap: no commercially licensed multitrack corpus.
- [VST3 in the plugin host](research/plugin-host-vst3.md) — VST3 SDK licence checked at the source (MIT since 3.8, 2025-10-29; Debian's 3.7.10 headers used under GPL-3: compatible). AGain gain exact, LSP limiter latency matches measured to the sample, also in a mixed LV2+VST3 chain and across a runtime look-ahead change (reported 35 ms late); crash, bus-mismatch and 8-channel liar refused. `getLatencySamples()` at activation was 0 for a 240-sample plugin.
- [LV2 plugin host, container](research/plugin-host-lv2-container.md) — `sonora-plugin-host` with eg-amp, x42-dpl and the LSP limiter: gain exact, reported latency matches measured to the sample and PDC nulls to 0, a segfaulting plugin kills only the host and is named, a late one is dropped then removed; round trip p50 62 µs / p99 252 µs (container). A timed wait overshot 2 ms by 5.9 ms once: argues for pipeline depth 1.

## Postmortems
- [2026-10-11 comment in a line continuation](postmortems/2026-10-11-comment-in-line-continuation.md) — dropped half a QEMU command line; bash -n cannot catch it. Also: an edit that reported success without landing.
